# 어휘 카드 게임

Unity로 제작 중인 한국어 어휘 학습 카드 게임입니다.  
카드를 사용할 때마다 퀴즈가 출제되며, 정답을 맞혀야 카드 효과가 발동됩니다.

---

## 개발 환경

- **Unity** 6000.3.10f1 (Unity 6)
- **플랫폼** Windows (StandaloneWindows64)
- **해상도** 1280 × 720

---

## 주요 기능

### 카드 시스템
- 손패에 최대 10장 보유, 5장으로 게임 진행, 부채꼴 정렬
- 카드 호버 시 확대 및 양옆 카드 밀림 효과
- 드래그 & 드롭으로 카드 사용

### 퀴즈 시스템
- 카드 사용 시 3지선다 퀴즈 팝업 출제
- 퀴즈 유형: 예문 속 단어 의미 맞히기
- 제한 시간 내 미응답 시 자동 오답 처리

### 카드 카테고리
| 카테고리 | 설명 |
|----------|------|
| 한자어 | 한자 기반 어휘 |
| 맞춤법 | 자주 틀리는 맞춤법 |
| 관용어 | 관용 표현 |
| 시사용어 | 시사·사회 어휘 |
| 고전 | 고전 문학 어휘 |

## 프로젝트 구조

```
Assets/
├── CardData/        # 카드 & 단어 ScriptableObject 데이터
├── Fonts/           # TMP 폰트 에셋 (네오둥근모Pro)
├── Prefabs/         # 카드 프리팹
├── Scenes/          # BattleScene, TitleScene
├── Scripts/
│   ├── Card/        # Card, CardHand, CardInteraction
│   └── Quiz/        # QuizManager, QuizPopup
└── Sprites/         # 카드 이미지, 타이틀 이미지
```

---

## 조작 방법

- **카드 호버** — 마우스를 카드 위에 올리면 확대
- **카드 드래그** — 카드를 드래그해서 드롭존에 놓으면 사용
- **퀴즈 응답** — 3개 보기 중 정답 선택 (제한 시간 10초)
- **카드 추가 (디버그)** — `1` 키로 랜덤 카드 추가
