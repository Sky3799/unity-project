# 어휘 카드 배틀 게임

Unity로 제작 중인 한국어 어휘 학습 카드 게임입니다.  
카드를 사용할 때마다 퀴즈가 출제되며, 정답을 맞혀 적을 쓰러뜨리세요.

---

## 개발 환경

- **Unity** 6000.3.10f1 (Unity 6)
- **렌더 파이프라인** URP
- **플랫폼** Windows (StandaloneWindows64)
- **해상도** 1280 × 720
- **Input System** New Input System

---

## 게임 흐름

```
타이틀 → 메인메뉴 → 스테이지 선택 → 난이도 선택 → 전투 → 결과
                  ↘ 수집 도감
                  ↘ 오답 노트
```

---

## 주요 기능

### 카드 시스템
- 손패 최대 5장, 부채꼴 정렬
- 카드 호버 시 확대 및 양옆 카드 밀림 효과
- 드래그 & 드롭으로 카드 사용

### 퀴즈 시스템
- 카드 사용 시 3지선다 퀴즈 팝업 출제
- 퀴즈 유형: 예문 속 단어 의미 맞히기
- 제한 시간 내 미응답 시 자동 오답 처리
- 정답 → 적 HP 감소 / 오답 → 내 HP 감소

### 스테이지 & 난이도
| 스테이지 | 테마 | 단어 유형 |
|----------|------|-----------|
| 1스테이지 | 산속 | 공문서·행정 한자어 (금일, 상기, 미결 등) |
| 2스테이지 | 서당 | 순우리말 날수·시간 표현 (사흘, 나흘, 닷새 등) |
| 3스테이지 | 저잣거리 | 고유어·생활 어휘 (나락, 이부자리, 두레박 등) |
| 4스테이지 | 궁궐 | 사회·경제·법률 한자어 (소급, 압류, 명도 등) |
| 5스테이지 | 저승문 | 혼합 |

| 난이도 | 적 HP | 오답 피해 |
|--------|-------|-----------|
| 1단계 | 100 | 15 |
| 2단계 | 150 | 30 |
| 3단계 | 200 | 50 |

> 스테이지 해금: 이전 스테이지 난이도 1·2·3 **모두** 클리어 시 다음 스테이지 해금

### AI 적응형 시스템 (구현 중)
- 오답 횟수에 따라 해당 카드 덱 출현 빈도 자동 조절
- Gemini API 연동으로 취약 단어 집중 문제 세트 생성

### 수집 도감
- 스테이지 클리어 시 몬스터 도감 해금
- 1스테이지: 호랑이 / 2스테이지: 도깨비

## 프로젝트 구조

```
Assets/
├── CardData/        # 카드·단어 ScriptableObject (40개)
├── Fonts/           # 네오둥근모Pro TMP 폰트
├── Prefabs/         # Card, DamagePopup, FadePanel
├── Resources/       # 클리어 이미지, 도감 이미지
├── Scenes/          # Title, MainMenu, StageSelect, Battle, Result, Collection, WrongNote
├── Scripts/
│   ├── Card/        # Card, CardData, CardHand, CardInteraction, WordData
│   ├── Quiz/        # QuizManager, QuizPopup
│   └── *.cs         # BattleManager, StageSelectManager, SceneFader 등
└── Sprites/         # Tiger, Goblin, Player, 배경, 타이틀
```

## 조작 방법

- **카드 드래그** — 카드를 드래그해서 필드에 놓으면 사용
- **퀴즈 응답** — 3개 보기 중 정답 선택 (제한 시간 있음)
